# ハッピーランド リニューアルの見本（制作会社に渡すもの）

**カテゴリ**: ハッピーランド（マッチングサイト）・本体の改善

ハッピーランドのリニューアルを制作会社に伝えるための、**押して動かせる HTML の見本**（スマホの画面）。公開先は https://happyland-support.github.io/renewal/index.html （GitHub Pages）。

- GitHub：`happyland-support/renewal`（**ichigo-support ではなく happyland-support のアカウント**。上げるときだけ `gh auth switch -u happyland-support` で切り替え、終わったら `gh auth switch -u ichigo-support` で戻す）。
- このフォルダのコミットの名前は happyland-support（このフォルダだけの設定）。
- 調査・直す候補・守るルールは 100 の README・`サイトの調査.md`・`サイト構築のルール.md`。

## 作り

- 手書きの HTML＋`css/styles.css`＋`js/main.js`（メニューの開け閉め・タブ）。Bootstrap Icons。
- **画面の状態ごとに1ページ**（例：`profile_08.html`＝プロフィール → OK返事受信 → ポイントあり）。`index.html` と、各メニューのページ（`mail.html` など）が目次。
- 1ページの中に「↓」で前後の状態を縦に並べることもある（仮登録の1問ずつの画面など）。

## 目次と見本ナビ（2026-10-16 から）

- `index.html` が**見本の目次**。分類ごとに、画面そのものを小さく表示して並べる（探す欄・「画面つき／一覧」の切り替えあり）。画面を押すと、その場でポップアップで大きく出る（← → で同じ分類の前・次、Esc で閉じる、「このページを開く」で別のタブ）。`index.html#view-profile_08.html` のように開くと、その画面を大きく出した状態で開く（制作会社に1画面を見せるとき用）。見た目は `css/catalog.css`、動きは `js/catalog.js`。
- **目次の中身は `js/catalog-data.js` の1か所だけ**。分類・画面のファイル名・名前（「→」で区切ると流れとして表示）・札（`tags: ["保留"]`）を書く。
- 各画面の最後の2行（`js/catalog-data.js` と `js/mihon-nav.js` を読む）で、画面の下に**見本ナビ**（前・次・目次。×で畳める）を出し、タブの題名をその画面の名前にする。見本を見て回るためだけのもので、本番には入れない。
- 各メニューの元の目次ページ（`search.html`・`mail.html` など）は、そのまま残している（目次の一番下からも行ける）。

### 画面を足すとき
1. 画面の HTML を作る（最後の `</body>` の前に、ほかの画面と同じ2行 `<script src="js/catalog-data.js"></script>` `<script src="js/mihon-nav.js"></script>` を入れる）。
2. `js/catalog-data.js` の、その分類の `items` に1行足す。
3. `py tools/check_catalog.py` で抜けを確かめる（目次に載っていない画面・ファイルが無い画面・見本ナビが無い画面・行き先の無いリンクを出す）。
